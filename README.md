# FitLog

FitLog is a responsive workout library that helps users explore exercises, view workout details, save workouts for later, and create a daily workout plan.

## Project Description

FitLog is a modern workout management website designed to make workout planning simple and organized.

Users can browse different workouts, view detailed exercise information, add workouts to today's plan, save workouts for later, sort workouts, and mark completed workouts.

The website is responsive and works smoothly on desktop, tablet, and mobile devices.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- Sonner
- Lucide React
- REST API
- LocalStorage

## Features

1. Responsive workout library
2. Workout details page
3. Add workouts to today's plan
4. Save workouts for later
5. Maximum 5 workouts in today's plan
6. Duplicate workout prevention
7. Sort workouts by duration, calories, and rating
8. Mark workouts as done
9. Remove workouts from plan or saved list
10. LocalStorage support
11. Toast notifications
12. Responsive design for desktop, tablet, and mobile

## API

FitLog uses workout data from a REST API.
